Glosario de Certificaciones y Especificaciones

Allison TES 668: Estándar más reciente de Allison. Obligatorio en transmisiones de nueva generación. El Syn ATF 668 es el único Chevron aprobado.
Allison TES 295/389/468: Estándares anteriores de Allison. El Syn ATF 668 es retrocompatible con los tres.
Eaton PS-386: Especificación de Eaton para transmisiones UltraShift AMT. Requiere viscosidad 75W-90.
Daimler MB 235.11: Aprobación oficial de Daimler para la transmisión DT-12 en Freightliner Cascadia y Western Star.
Volvo 97305 / 97307 / 97318: Especificaciones Volvo para transmisiones iShift. Aplica también a Mack mDrive.
Dana SHAES 256 Rev C: La especificación más exigente de Dana para ejes de alto rendimiento. Solo Syn-Gear XDM la cumple.
Meritor O-95 / O-76: Especificaciones de Meritor para ejes traseros con drenaje extendido.
API GL-5 / MT-1: Categorías API para lubricantes de engranajes hipoides (GL-5) y transmisiones manuales de camión (MT-1).
ZF TE-ML: Serie de especificaciones de ZF para transmisiones y reductores. Diferentes sufijos (03D, 04D, 05A...) aplican a distintos productos.
SAE J2360 / MIL-PRF-2105E: Estándar SAE equivalente al militar MIL-PRF-2105E. Requerido por muchos OEM para ejes y diferenciales.
