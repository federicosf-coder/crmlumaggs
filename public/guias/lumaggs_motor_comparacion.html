Glosario de Certificaciones

API CK-4: La categoría API más reciente para motores diesel de servicio pesado (2017+). Compatible retroactivamente con CJ-4, CI-4 Plus, CI-4 y CH-4.
API FA-4: Categoría exclusiva para máxima eficiencia de combustible en motores 2017+ que permiten aceites de baja viscosidad HTHS. No intercambiable con CK-4.
ACEA E11: La especificación europea más reciente para aceites de motor diesel de servicio pesado. Equivalente europeo del CK-4.
ACEA E4 / E7: Especificaciones europeas para motores con drenaje extendido. Requeridas por Scania, Volvo, MAN, Mercedes y DAF con tecnologías Euro IV-VI.
Cummins CES 20086: Especificación Cummins para el nivel CK-4. Aplica a todos los motores Cummins X15, X12, L9, B6.7 modernos.
Cummins CES 20087: Especificación Cummins específica para API FA-4. Solo motores 2017+ que el OEM aprueba para ese grado.
Detroit DFS 93K222: Especificación de Detroit Diesel para los motores DD15, DD13 y DD8. Equivalente al CK-4.
Mack EOS-4.5: Especificación Mack para motores MP7, MP8 y MP10 con tecnología CK-4.
Volvo VDS-4.5: Especificación Volvo para motores D11, D13 y D16. Requerida también en modelos VNL y FH más recientes.
MB 228.31 / 228.51: Aprobaciones Mercedes-Benz para motores OM471/OM470/OM936. La 228.51 es más exigente y requiere aceite sintético.
JASO DH-2: Especificación japonesa para aceites de motor diesel de servicio pesado. Requerida por Isuzu y Hino para cumplimiento en mercado japonés.
API CF-2: Categoría para motores diesel de 2 tiempos fuera de carretera (Detroit Serie 149). Solo el Delo 100 Motor Oil la cumple en el portafolio.
